## Installation

### Linux

```bash
# Install latest
curl -fsSL https://bit.ly/nagato-linux | bash
```

```bash
# Install nightly
curl -fsSL https://bit.ly/nagato-linux | bash -s -- nightly
```

### Windows

```powershell
# Install latest
irm https://bit.ly/nagato-windows | iex
```

```powershell
# Install nightly
$env:NAGATO_VERSION='nightly'; irm https://bit.ly/nagato-windows | iex
```
